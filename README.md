# Шагала, 13: смета и сценарии уменьшения платы

- `index.html` — исходная санкей-диаграмма сметы ОСС.
- `recalculation.html` — самостоятельная страница расчёта для квартиры/нежилого помещения и машино-места/кладовой. Открывается прямо с диска, без установки и интернета. Для передачи жителям достаточно этого одного файла.

## Как пользоваться

Выберите тип помещения, исходную базу, площадь по квитанции, месяц, число дней нарушения и сценарий. Можно изменить долю затронутой стоимости каждой работы и ввести фактические ставки. Таблица сравнения показывает ставку и месячную сумму до и после выбранного уменьшения. Кнопка «Скачать свой расчёт» создаёт отдельный HTML-файл с выбранными параметрами, который можно открыть на другом компьютере без интернета. Кнопка печати сохраняет условия расчёта; кнопка копирования записывает параметры в адрес страницы. Локальная ссылка имеет путь конкретного компьютера: передавая файл другому человеку, приложите распечатку или сообщите параметры.

Сценарии — арифметические ориентиры при подтверждении включённых в начисления работ, затронутого объёма и периода нарушения. Проценты в готовых вариантах не являются установленной актом оценкой качества. Смета используется для расчёта стоимости и не означает признания законности оспариваемого ОСС. Это не утверждённый новый тариф и не гарантированный возврат.

Квартирный пример основан на сверке квитанций января–сентября 2026. Это не текущая ставка для любого помещения. Квитанции паркинга, кладовых и иных нежилых помещений не сверены; сметные 7,08 за «Умный дом» не доказывают его фактического начисления/применимости для паркинга. Ввод фактических ставок предусмотрен для сопоставления со своим счётом. Первичные документы и персональные данные не включены в репозиторий.

Ориентиры из совокупного требования по акту осмотра 15.09.2026:

- Б = 13,33: растения в холлах 3,33 + газоны 1,60 + домофон 3,64 + автоматические двери 4,76.
- Б = 19,33: те же четыре работы и ежегодная мойка фасада 6,00. Варианты 13,33 и 19,33 не складываются.
- Д — другие подтверждённые уменьшения, включая уборку, СКУД, ТО АЗУ, участок и прочие работы. Неопределённая Д не считается доказанным нулём.
- Уборка паркинга — отдельная сметная строка 312,46, обозначенная «только м/м». Для кладовых её применять лишь после подтверждения начисления, даже если исходная страница объединяет оба вида помещений одним переключателем.

Снижение квартирного содержания на 2,67 совпадает со строкой СКУД, но его назначение не подтверждено. В квартирном примере включена явно обозначенная гипотеза, исключающая повторное вычитание СКУД. Её можно отключить для сравнения; дополнительное вычитание тогда требует установления назначения прежнего снижения. В других базах такую корректировку модель сама не предполагает.

Полное невыполнение всех видов уборки нельзя выводить из грязи на полу. Полное невыполнение содержания участка нельзя выводить из отсутствия озеленения. Дефекты экранов/кнопок лифта не доказывают невыполнение всех работ по лифтам. Для ежегодных/сезонных работ требуется установить нарушенный срок и объём. Общие работы применимы к другим лицевым счетам при подтверждении их начисления и затронутых объектов.

Охрана, строймусор и «Умный дом» сохранены в исходной композиции платежей. Калькулятор количественно уменьшает только содержание. Самостоятельные требования по отдельным сборам нуждаются в собственных основаниях и расчёте.

## Расчёт

Ориентир по [п. 10 Правил изменения размера платы, ПП РФ № 491](https://www.consultant.ru/document/cons_doc_LAW_62293/8b2eaf4c7acc1ba1061b45e44d06298a48c90531/):

`уменьшение по работе = стоимость работы за месяц × доля затронутой стоимости × дни нарушения / дни месяца`

Уменьшения Б и Д складываются без повторного включения одной работы. Сумма свыше исходного содержания вызывает ошибку, вместо показа отрицательного платежа. Каждая строка начисления округляется отдельно до копеек; из исходной суммы содержания вычитается отдельно округлённая сумма уменьшения. Поэтому возможна разница в 1 копейку с умножением агрегированной ставки на площадь. Другие начисления добавляются вручную, их модель не уменьшает. Отдельный уже возвращённый платёж учитывается в дополнительном перерасчёте за месяц, но не меняет будущую месячную плату.

Каждый прошлый месяц рассчитывается отдельно: ставки, дни, объём и прежние корректировки могут отличаться. Для будущих месяцев уменьшение зависит от сохранения нарушений и прекращается по соответствующим работам после их восстановления.

## Контрольные примеры полного месяца

| Условный вариант | Снижение, руб./м² | Уменьшение в месяц, руб. | Содержание после, руб./м² |
| --- | ---: | ---: | ---: |
| Квартира 40,7 м², Б | 13,33 | 542,53 | 144,00 |
| Квартира 40,7 м², Б с мойкой | 19,33 | 786,73 | 138,00 |
| Квартира 40,7 м², расширенный Б+Д, СКУД уже исключён по гипотезе | 51,54 | 2 097,68 | 105,79 |
| Паркинг 13,3 м², 100% строки уборки | 312,46 | 4 155,72 | 160,00 |
| Паркинг 13,3 м², расширенный Б+Д и 100% строки уборки | 366,67 | 4 876,71 | 105,79 |

Расширенные варианты — условия полного затронутого объёма, а не доказанный итог акта. В варианте с одной уборкой паркинга сумма сметных строк снижается с 9 436,75 до 5 281,03 руб. за месяц; при расширенном варианте — до 4 560,04 руб. Коммунальные и иные начисления в эти суммы не входят.

## Проверка

Без сторонних зависимостей:

```sh
node --test tests/recalculation.test.cjs
```

Тесты проверяют данные исходной сметы, суммы и округление строк, альтернативы Б, прежнее исключение СКУД, парковочную уборку, частичный период, ранее возвращённые суммы, недопустимые вводы и отсутствие внешних скриптов/личных идентификаторов. Модель находится в отдельном блоке скрипта внутри страницы; интерфейс и модель используют одни данные.
